Operating principles

  1. One identity. Sensitive applications share a central authentication and authorisation layer.
  2. Clear ownership. Files, contacts, calendars, structured data, and notes each have an explicit source of truth.
  3. Small public surface. A public gateway terminates encrypted connections; storage-heavy services remain on private hardware.
  4. Recoverable by design. Data is backed up independently of the running applications and storage device.
