# utkubilen.de

Static personal website and cloud portal for [utkubilen.de](https://utkubilen.de).

The site intentionally has no build step, JavaScript, analytics, cookies, or runtime third-party dependencies. It is served by GitHub Pages from the `main` branch.

Typography uses self-hosted iA Writer Duo and Mono webfonts under the SIL Open Font License. The layout follows Tufte-style principles without loading an external stylesheet.
